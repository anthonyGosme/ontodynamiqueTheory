1. OVERVIEW
───────────────────────────────────────────────────────────────

Two R-XVII tests on Saccharomyces cerevisiae:

  A) EXPLORATORY — homozygous deletions (complete knockout)
     Ratio S/I = 1.42× [1.31, 1.54], p = 3.9×10⁻¹⁹
     273 Hillenmeyer chemical stress screens
     Robustness: SUCCÈS FORT (6/7)

  B) CONFIRMATORY — heterozygous deletions (haploinsufficiency)
     Pre-registered on OSF: https://osf.io/s7cn9/overview
     Ratio S/I = 1.18× [1.12, 1.24], p = 1.5×10⁻¹⁴
     6,946 all-chemical screens (no Hillenmeyer in het collection)
     4/4 pre-specified criteria met

6. PARTITION DETAILS
───────────────────────────────────────────────────────────────

  STRUCTURE (23 GO terms): DNA repair, proteasome, chaperones,
  ERAD, cell cycle/division, DNA replication, cell wall,
  mitochondria, ribosome biogenesis, chromatin, chromosome
  segregation.

  INPUT (24 GO terms): signal transduction, MAPK, GTPase, GPCR,
  TOR, phosphorylation, transmembrane/ion transport, stress
  response (osmotic, heat, oxidative, salt).

  Classification rule: STRUCTURE-only / INPUT-only / BOTH (excluded).
  Annotations: direct only (no OBO hierarchy propagation).
  Full term lists: see gene_classification.tsv and CR document.


7. KEY DIFFERENCES BETWEEN HOM AND HET
───────────────────────────────────────────────────────────────

                          HOM (Test A)        HET (Test B)
  ─────────────────────── ─────────────────── ──────────────────
  Collection              haploid/hom diploid  het diploid
  Mechanism               complete KO          haploinsufficiency
  Essential genes         absent               present
  Genes in matrix         4,554                5,639
  Matched S / I           713 / 509            1,125 / 538
  Hillenmeyer screens     273                  0
  Chemical screens used   273 (Hillenmeyer)    6,946 (all chem.)
  Ratio S/I               1.42×                1.18×
  Status                  exploratory          confirmatory (OSF)

  Why het ratio is lower:
  1. Haploinsufficiency is milder than complete knockout
  2. All-chemical screens (broad) vs Hillenmeyer (curated, strong
     perturbations) — dilutes the signal
  Both factors were anticipated in the pre-registration.

    Permutation: seed=42
